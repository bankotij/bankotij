## A few projects to explore

- **[CartShield](https://github.com/bankotij/cartshield)** — checkout orchestration with idempotency keys, persisted saga steps, retries and compensation. Payment and inventory providers are simulated so the failure paths can be inspected locally.
- **[Ecommerce Cart API](https://github.com/bankotij/ecommerce-cart-api)** — a small TypeScript service with server-owned prices, immutable order snapshots and single-use discount codes.
- **[Donizo](https://github.com/bankotij/Donizo)** — renovation scope extraction that keeps provenance, conflicting evidence and pricing blockers alongside its structured output.
- **[Working tools](https://bankoti-workbench.netlify.app/jay/)** — try JSON Contract Desk in the browser: infer a response contract, catch a breaking change, and export TypeScript.
