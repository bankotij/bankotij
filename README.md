# Jay Bankoti · Bankoti Studio

I build the software behind the interface: APIs, operational tools, AI evaluation systems and workflows that need to recover when a request fails.

[Bankoti Studio](https://www.bankoti.com) is where I take on product engineering projects and ongoing development retainers. Start with a defined problem, ship a useful release, then keep improving it with the people using it.
